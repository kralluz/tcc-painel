Travando o caminho

Decisões que dependem de alguém antes de seguir.

    Sincronização

    —

    Conectar ou trocar o token do GitHub
    1. Abra github.com/settings/personal-access-tokens/new.
    2. Em Repository access, escolha Only select repositories e marque só o repositório de textos.
    3. Em Permissions → Contents, escolha Read and write. Gere e copie o token.
    4. Cole abaixo. Faça isso uma vez em cada aparelho.

    O token fica guardado só neste aparelho e só dá acesso ao repositório de textos.
